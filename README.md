# 📝 Forma e Thjeshtë HTML

Formë kontakti e thjeshtë me stilim CSS — fusha për emër, email, telefon, website dhe mesazh, me validim të integruar HTML5.

## 🚀 Si ta hapësh

Hap `index.html` në browser, plotëso fushat dhe kliko **Submit** — fushat required validohen nga browser-i.

## 📁 Struktura

```
Simple-HTML-Form/
  demo/
  demo/index.html
  demo/style.css
  original/
  original/index.html
  original/style.css
  index.html          (showcase: Live Demo + Kodi Burim)
  README.md

```
